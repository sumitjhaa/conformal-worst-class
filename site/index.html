Conformal classification · MNIST · CIFAR-10 · CIFAR-100 · ImageNet

How small can a trustworthy prediction set be, and who does it leave out?

A classifier normally gives one answer. Conformal prediction makes it return a set of labels that contains the truth at least 1 − α of the time, for any model, with a finite-sample proof. That promise is an average. This project measures, predicts and repairs the classes it leaves behind. Drag α and watch the sets change on real test images.

1 · Question & scope

A set, a promise, and what the promise leaves out

Take a fixed, already-trained image classifier. At prediction time we see one image and nothing else. We want a set C(x) ⊆ {1,…,K} with P(Y ∈ C(X)) ≥ 1 − α. Every valid method meets that bar, so three questions remain: (i) how small are the sets (efficiency), (ii) does every class get its share (class-conditional coverage), and (iii) can we predict and repair the worst class when there are many classes and few calibration images per class.

Unit

One row = one image and its true class. The output is a label set, not a single prediction.

Claim

Marginal coverage ≥ 1 − α over exchangeable data; an exact law for the worst class under class-wise calibration; a high-probability fix and its cost.

Not claimed

Nothing causal, no accuracy race, no guarantee for one image or under shift. A bigger set is not "worse" if it is honest.

2 · Data & preprocessing

Five settings, four disjoint splits, one rule

MNIST (LeNet), CIFAR-10 (small ResNet, and an ImageNet-pretrained ResNet-18 as a second architecture), CIFAR-100 (small ResNet) are trained here; ImageNet uses published ResNet-152 outputs on its 50,000 validation images. The official training set is cut once per seed into four disjoint parts, each with one job. The official test set is used once, for the reported numbers.

D_train · fit

Network weights, normalisation stats, class means and shared covariance for the Mahalanobis distance, feature clusters for stratified coverage.

D_design · tune

Temperature T, RAPS λ/kreg, SAPS λ, γ, the learned score, the class clusters, early stopping. Never used for q̂.

D_cal · calibrate

Only the conformal thresholds q̂. Touching it while tuning would break exchangeability and the guarantee.

D_test · report

The official test split, opened once. Shift sets (CIFAR-10.1, CIFAR-10-C, rotations, noise) are evaluation-only.

Quality checks: the split assertion verifies disjointness and completeness; classes are balanced (MNIST 9–11%, CIFAR exactly uniform, ImageNet 50 per class); normalisation is fit on D_train only; augmentation (flip + crop) is train-only. ImageNet has no images or features in the published file, so feature-based methods are skipped there; its 50k images are re-split 20/40/40 per seed. SVHN was planned as an unfamiliar-input set but its host was down during the final run.

3 · Baseline & methods

Every method is "pick a score, pick who shares a threshold"

Split conformal works with any score s(x, y), where smaller means "y looks right for x". Score the true label of each calibration image, take an order statistic, include every label below it. Methods differ in the score and in which calibration images share a threshold: all of them (marginal), one class (Mondrian), or a cluster of similar classes.

5 · Depth · the theorem, checked

Is the guarantee real?

The coverage of a single calibrated predictor is itself random: it depends on which n images landed in D_cal. Under exchangeability the rank of a new score among the n calibration scores is uniform, which gives the exact law coverage | D_cal ~ Beta(k, n+1−k). Here we pool D_cal and D_test, re-split 400 times, and compare the histogram with that exact law (convolved with the test-set binomial). Uses the Set lab's dataset, n and α.

8 · Theory · the worst class, predicted

The worst class follows an exact law

With one threshold per class, each class's coverage is its own Beta(kc, nc+1−kc), and the classes are independent because their calibration images are disjoint. Measured on m test images each, the worst class is the minimum of K Beta–binomials: P(min ≥ t) = Πc P(covc ≥ t). So the worst class is predictable before running anything, and it gets worse with K.

9 · Method · fixing the worst class

A guarantee for every class, and what it costs

Mondrian-PAC picks a stricter order statistic per class so that all classes reach 1 − α together with probability ≥ 1 − δ. With few images per class that is expensive, or impossible: below about ⌈log δ_g / log(1−α)⌉ images a class can only be covered by including its label always. Pooling similar classes into M clusters gives each threshold more data. M = 1 is ordinary marginal conformal, M = K is Mondrian. The curve shows the trade-off.

13 · Depth · diagnostics

Two things explained

Why empty sets appear

If every set has at most one label, a miss is either an empty set or a wrong top-1, so P(empty) ≥ accuracy − coverage. When accuracy beats 1 − α, conformal must hand out empty sets.

Each dot: one run × seed × α where the bound applies (Naive scores). Dashed: equality.

Why the distance term adds little

A set grows by admitting the second most likely label. How well does each signal tell whether that label is the true one?
